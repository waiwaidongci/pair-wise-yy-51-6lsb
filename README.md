# 铁路危险货物运输路径审批与风险复核平台

源提示词编号：8。包含危险货物运输单编组、候选路径生成、MapLibre 路网风险叠加、Turf 里程测算、安全/运营/应急逐区段会签、替代方案与审计基线。

## 共享封锁快照（协同一致性）

路径草案、风险复核、多角色会签与里程计算共用同一份封锁快照（`RoutePackage.snapshot`）：

- **范围变更立即联动**：任一调度调整封锁/慢行/开通范围，快照修订号 +1，受影响区段的复核与会签立即标记失效，Turf 里程（总里程与封锁折算里程）在同一 reducer 事务内同步重算。
- **并发保存**：保存请求带 `baseRevision`（乐观锁）。两个调度先后保存时，先到结果立即生效；后到请求因修订号落后整体进入「冲突待办」，不覆盖先到内容，由本班调度选择采纳合并（修订再 +1 并再次失效受影响复核）或放弃。
- **断网巡查单**：断网期间填写的巡查单持久化到本机（localStorage），联网后按原单号 `sheetNo` 合并而非新建；客户端 `token` 保证写入失败重试的幂等——已被服务端受理的 token 无论重放多少次都沿用首次结果。
- **锁定前逐项确认**：复核全部重做并接受、里程已复核、冲突待办与离线单清零等检查项逐项勾选后才能锁定快照；锁定后封锁范围只读。
- **统一待复核口径**：工作台、风险地图、审批页顶部的「待复核 N」均取自同一 NgRx 选择器（失效或未接受的复核/会签）。

## 技术栈

Angular、Angular Material、NgRx、Angular Router、HttpClient、RxJS、MapLibre GL、Turf.js、TypeScript。
